# Project Context / Контекст проекта

FoodAI Ecosystem — коммерческий продукт для ведения питания и физической активности с компьютерным зрением и AI.

## Основной сценарий

1. Пользователь фотографирует еду.
2. Система распознаёт продукты и ингредиенты.
3. Система оценивает порцию и массу.
4. Система рассчитывает калории, белки, жиры, углеводы и другие нутриенты.
5. Пользователь подтверждает или исправляет результат.
6. Подтверждённые данные сохраняются в дневник.
7. Система анализирует дневной рацион.

## Языки

Основные языки проекта и пользовательского продукта: русский (`ru`) и английский (`en`).

Пользовательские тексты, уведомления, safety-инструкции, consent-тексты, справка и публичные материалы должны планироваться для обоих языков.

## Будущие направления

- AI-помощник по питанию.
- AI-тренер.
- AI-помощник по привычкам и самочувствию.
- Тренировки.

## Safety-позиционирование

AI не позиционируется как врач, лицензированный нутрициолог, психолог или система медицинских решений.

AI не должен:

- ставить диагнозы;
- назначать лекарства;
- заменять врача;
- самостоятельно принимать медицинские решения.

Потенциально опасные ситуации требуют отдельной safety-логики.

## Роли

- `anonymous`: неавторизованный посетитель.
- `user`: обычный пользователь, имеет доступ только к собственным данным.
- `support`: техническая поддержка без доступа по умолчанию к дневнику, фотографиям, AI-диалогам и health profile.
- `content_manager`: управляет каталогом продуктов, нутриентами, справочниками и контентом.
- `admin`: управляет системой и пользователями согласно permissions.
- `superuser`: технический системный доступ, не для повседневной работы.
