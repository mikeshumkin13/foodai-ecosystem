# FoodSeg103 validation fixture

`foodseg103_examples.png` получен с официальной страницы проекта FoodSeg103:

- source: https://xiongweiwu.github.io/foodseg103_files/foodseg103.png
- project: https://github.com/LARC-CMU-SMU/FoodSeg103-Benchmark-v1
- authors: Xiongwei Wu, Xin Fu, Ying Liu, Ee-Peng Lim, Steven C.H. Hoi, Qianru Sun
- project license: Apache License 2.0
- retrieved: 2026-08-28

В benchmark используются только восемь crop-областей исходной демонстрационной фигуры. Fixture не
содержит пользовательские фотографии FoodAI и не используется для обучения модели.

Лицензия repository/dataset project указана авторами как Apache-2.0. Перед коммерческим production
launch всё равно требуется отдельная юридическая проверка прав на исходные изображения и provenance
обучающих данных моделей.
